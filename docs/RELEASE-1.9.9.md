# AG Cleaner 1.9.9 更新说明

一句话：清理结果说得更干脆，误判也压下去了。

## 本次更新

- **完成页只说结果**：清完只显示「清理完成」四个字，预计、实际、被谁占用、未清理清单这些数字不再铺在界面上，免得越看越糊涂；需要查细节仍可在操作日志里看
- **不再把正在用的软件当成残留**：正在运行的程序所在目录不会再被判成「孤儿目录」，可清理量比之前可信
- **单项可删**：清单里点进详情，可以只删这一项，二次确认后执行，删完回写剩余体积
- **界面统一**：关于页信息居中，小窗口下文字不再被裁，按钮与清单不重叠，一屏放得下
- **六种语言对齐**：中文 / English / Deutsch / Français / Русский / Español 的说明与按钮全部补齐，顶栏切换即时生效
- **扫描更稳**：扫描与清理共用居中的进度提示，进度不再长时间停在同一个数字上

## 下载与安装

单文件 exe，免安装，约 880 KB；依赖 Windows 10 / 11 自带的 .NET Framework 4.8；不联网，不上传任何清单。

## 说明

本版本包含自 1.8.5 以来的全部改动，都归在上面这几类里：界面、清理判定、操作便利、语言与稳定性。
